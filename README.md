# Three Questions — Leo Tolstoy
### A Realm of English (B) Selection | Interactive Educational PWA

A complete offline-first Progressive Web App for Bengali-medium Class IX–XII students studying Leo Tolstoy’s short story **Three Questions**.

## Live site

https://pbwsantu-collab.github.io/three-questions-tolstoy-pwa/

## Files needed for a working deploy

| File | Purpose |
|------|---------|
| `index.html` | Complete single-file application (~104 KB) |
| `manifest.json` | PWA manifest |
| `sw.js` | Service worker |
| `README.md` | This file |

## How to deploy the full app

1. Download the complete package (zip) from the conversation with Grok, **or** copy `index.html` from the project folder.
2. In this repo: **Add file → Upload files**
3. Upload `index.html` (overwrite the existing placeholder/loader)
4. Commit to `main`
5. Enable **Settings → Pages → Deploy from branch → main / root**

## Features

- Complete textbook text (Pages 168–172) with original footnotes
- Clickable vocabulary with Bengali meaning, pronunciation & part of speech
- Paragraph-level Bengali translations
- Browser TTS with paragraph highlighting
- Read / Listen / Learn modes
- Vocabulary panel, quiz, progress dashboard
- Settings (theme, font size, etc.)
- Offline PWA support

**Core loop:** SEE → HEAR → CLICK → UNDERSTAND → REPEAT → PRACTISE → MASTER
